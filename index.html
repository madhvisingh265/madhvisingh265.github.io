BESS health monitoring

Can we warn an operator before a battery cell fails, without taking it offline?

Python, scikit-learn, Streamlit, Plotly

Built
A health model that estimates each cell's state from voltage, temperature and resistance, an end-of-life forecast, anomaly flags and a live dashboard. Uses NASA's battery ageing data (4 cells, 636 cycles).
Result
Every cell that reached end of life was flagged 17–36 cycles in advance. Health estimates on unseen cells were within 2.8 points on average.
So what
That warning window is when replacement can be planned instead of becoming downtime.
Code and results

E-commerce returns risk

Which orders are likely to come back, and what can we do before they ship?

Python, pandas, scikit-learn

Built
A process analysis of where returns come from, plus a checkout-time risk model, on a 5,000-order simulated dataset with every assumption written down.
Result
Flagging the riskiest 20% of orders catches 42% of all returns. Size and fit alone cause a third of them.
So what
Act on the flagged orders: a size check, a prepaid nudge for COD, or priority dispatch when delivery is late.
Code and results

Netflix content strategy in SQL

What does Netflix's catalogue say about its strategy for India?

SQL (CTEs, recursive CTEs, window functions), SQLite

Built
Ten SQL queries on 7,787 titles, covering catalogue growth, genre momentum, an India vs US comparison, audience mix and renewal rates.
Result
India is the #2 source country, but 915 of its 990 titles are films. Two-thirds of all shows never get a second season.
So what
The gap is Indian series, the format that keeps subscribers coming back.

DC-DC buck converter

Can a 12 V to 5 V converter hold its output steady when the load suddenly doubles?

Power electronics, control, Python simulation

Built
Component sizing and a loss budget, a switching-level simulation and a PID controller with soft-start, alongside a hardware prototype.
Result
Back within 1% of 5 V in 0.23 ms after a 0.5 A to 1 A load step. Estimated efficiency is 93%.
So what
A plain PI loop made the filter ring. Finding and damping that was the real engineering.
Design and simulation

ADHD detection from EEG

Can brain signals recorded during an attention task help screen children for ADHD?

PyTorch, EEGNet + LSTM, signal processing

Built
A deep-learning model (EEGNet for spatial and frequency patterns, LSTM for how they change over time) trained on 19-channel EEG from 121 children.
Result
87.6% accuracy across 121 children, catching 55 of 61 ADHD cases (ROC-AUC 0.93). That's about 12 points better than my earlier feature-based Random Forest.
How it's tested
Each child is tested only by a model that never saw their data, so the model can't score well just by recognising the child.

How I work

What I've learned so far in a founder's office.

Commit to outcomes

"Work on hiring" is an activity. "Fifteen scored profiles in the tracker" is an outcome the founder can check at 7:30 PM.

Problem first, data second

A brief opens with the problem and the use case. Numbers support the argument from the appendix. They don't replace it.

Same yardstick for everyone

Every candidate for a role gets the same core questions and the same rubric, and every score is backed by what they actually said.

Free before paid

Before asking for a subscription, I check whether a script or a free tool can do the job.

Honest numbers

If a result is simulated, projected or measured on a small sample, it says so next to the number.

Engineer's habit

When something breaks, find the root cause and fix the system so it doesn't happen again.
